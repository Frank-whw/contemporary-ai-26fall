# contemporary-ai-26fall

当代人工智能实验课共用仓库。依赖由根目录 `uv.lock` 锁定，各实验放在各自子目录，脚本用相对路径读数据。

进度先本地commit，临近ddl再push到GitHub，避免nothing for something的情况。若助教/老师发现进度落后，可以提醒一下我:)

## 环境

- Python ≥ 3.12（`.python-version` 为 3.12）
- [uv](https://docs.astral.sh/uv/)
- 本次锁定：scikit-learn 1.9.1、numpy 2.5.3、scipy 1.18.1、pandas 3.0.5、matplotlib 3.11.2
- 本机：macOS arm64，只用 CPU
